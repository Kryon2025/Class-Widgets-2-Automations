当前版本 v3.2.0 完整日志见仓库 CHANGELOG.md

此处仅摘录主要版本节点，完整历史见仓库 CHANGELOG.md。

v3.2.0

  • 倒计时提醒（行动）：每秒刷新「还剩 N 秒」，结束后才执行下一步；
  • 空闲触发器：键鼠无操作达设定时长触发一次；
  • 时间段触发器：精确到秒、可跨零点，离开可自动还原；
  • 时间区间判定：「时间在…与…之间」条件；
  • 快捷面板「快捷管理自动化」：托盘里勾选即改、立即保存；
  • 修复媒体控制重启后失效、通知恢复显示互打断等问题；
  • 本仓库 上课/下课触发器限定当天第几节课（PR #3）；LICENSE 恢复纯标准 MIT（PR #3）。

v3.1.0

  • 合并回主线：3.0.x 曾以独立 ID 单独发版，自此统一回 com.kryon.automations，规则自动迁移；
  • 本仓库 新增「播放文字」：全屏 / 顶部横幅两种模式，横幅高度按字号自适应；
  • 本仓库 供其它插件调用的 playBanner(text, duration) 接口；上课/活动期间一律拒绝外部推送；
  • 本仓库 编辑面板「滚不到底」根修（面板挂窗口根节点、高度真量窗口）、参数换行适配。

v3.0.x

  • 3.0.5：上课/活动期间拒绝远程横幅，上课铃响自动撤掉已显示的远程横幅；
  • 3.0.4：到时也不切断滚动文字，等整段滚出屏幕再关；新增 playBanner 接口；
  • 3.0.2~3.0.3：播放窗口不进任务栏、停留 0 秒 = 一直显示；
  • 3.0.1：横幅高度按字号自适应、离顶部留 4.5% 屏高；
  • 3.0.0：新增「显示方式」（全屏 / 顶部横幅）。

v2.x（「更好的自动化」独立发版期）

  • 2.2.x：编辑界面在窗口缩放下重排、全屏播放文字右键菜单、触摸屏长按支持；
  • 2.1.x：新 ID 发布、上课/下课触发器科目限定（p1）、「课程展示模式」行动、旧插件规则自动迁移；
  • 2.0.x：规则导入/导出（带预览、合并/替换、上限保护）、保存逻辑重做（弱机不再卡顿）。
