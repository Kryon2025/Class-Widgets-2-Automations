第几节课限定 v3.2.0 新增

来源 PR #3 适用 上课时 / 下课时 可选范围 第 1~20 节

上课/下课触发器新增「当天的第几节课」下拉，让规则只在特定节次的课堂时段生效。

入口位置

新建或编辑自动化时，触发器选「上课时」或「下课时」，参数区出现两个下拉：

  • 科目：限定只在某科目时触发，留「任意课」= 每节都触发；
  • 第几节课：限定只在当天第 1~20 节时触发，留「不限」= 每节都触发。

两个条件同时填写时需都满足才触发。

计数规则

场景计数方式
上课时当前这节课在当天所有上课条目（按开始时间排序）中排第几
下课时刚结束的那节课在当天排第几
条目类型课程与活动都计入（与 CW2 主程序课表口径一致）
取不到节次时判定不通过，规则不触发（按 0 处理）

例：课表含 4 节课 + 1 个活动，下午那节课在全天按开始时间排第 5 位，它的「第几节课」就是 5。

典型用法

  • 只在第一节上课时提醒：触发器「上课时」+ 节次「第 1 节」→ 晨读开始提醒；
  • 最后一节下课时收尾：触发器「下课时」+ 节次选当天最后一节 → 放学清理；
  • 特定科目特定节次：科目与节次叠加，例如只在「第 3 节的数学」上课时弹出某程序。
