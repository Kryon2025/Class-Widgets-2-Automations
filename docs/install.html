安装与更新

插件 ID com.kryon.automations 最新版 v3.4.0 API ~=0.7.0

方式一：插件市场（推荐）

  1. 打开 Class Widgets 2 的「设置 → 插件」；
  2. 进入插件市场（自动化广场），搜索「Kryon的自动化」或「自动化」；
  3. 安装后重载插件即可。

市场版本由主仓库的 Release 工作流自动发布，与 GitHub 上的最新版本一致。

方式二：手动安装

  1. 到主仓库 Releases 页面 下载当前版本的 .cwplugin 安装包；
  2. 双击安装，或解压到 CW2 的 data/plugins/com.kryon.automations/；
  3. 重启 CW2 或在插件设置中重载。

从旧版「更好的自动化」迁移

2.1.0–3.0.x 期间，插件曾以独立 ID org.cslblog.betterautomations（名称「更好的自动化」）单独发版；自 v3.1.0 起统一回主线 ID com.kryon.automations（名称「Kryon的自动化」）。升级后首次启动时，如果本插件还没有自己的配置，会自动把旧插件的配置文件复制过来，原有规则不需要重新配置。如果旧插件「更好的自动化」仍处于启用状态，设置页会出现一条警告提示条，并发送一次系统通知，提醒停用或卸载——否则两套引擎会重复触发同一条规则。

验证安装

安装成功后，新建一条自动化，触发器下拉中应能看到「上课时」「下课时」等选项；选择「上课时」后参数区出现「科目」与「第几节课」两个限定条件。
