安装与更新

插件 ID com.kryon.automations 最新版 v3.2.0 API ~=0.7.0

方式一：插件市场（推荐）

  1. 打开 Class Widgets 2 的「设置 → 插件」；
  2. 进入插件市场（自动化广场），搜索「更好的自动化」或「自动化」；
  3. 安装后重载插件即可。

市场版本由主仓库的 Release 工作流自动发布，与 GitHub 上的最新版本一致。

方式二：手动安装

  1. 到主仓库 Releases 页面 下载当前版本的 .cwplugin 安装包；
  2. 双击安装，或解压到 CW2 的 data/plugins/com.kryon.automations/；
  3. 重启 CW2 或在插件设置中重载。

从旧版「更好的自动化」迁移

v3.0.x 时期插件曾以独立 ID org.cslblog.betterautomations 发布，自 v3.1.0 起回归主线 ID。首次启动会自动把旧规则文件复制过来，原有规则不需要重新配置。若旧插件「Kryon的自动化」仍在启用，设置页顶部会显示提示条提醒停用。

验证安装

安装成功后，新建一条自动化，触发器下拉中应能看到「上课时」「下课时」等选项；选择「上课时」后参数区出现「科目」与「第几节课」两个限定条件。
