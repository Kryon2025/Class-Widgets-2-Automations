行动一览

内置 17 种 一条自动化可挂多个行动

行动是自动化被触发后依次执行的动作。同一条自动化可组合多个行动，用「等待」行动控制节奏。

系统与设备

行动说明
运行命令/程序执行命令行或启动程序
应用管理打开 / 关闭应用，支持从应用列表选择（含开始菜单 .lnk、UWP）
电源关机 / 重启等电源操作
音量调整系统音量
媒体控制播放 / 暂停等 SMTC 媒体控制；播放器未就绪时自动重试最多 10 秒
锁定配置项防止配置被改动
重启主程序重启 Class Widgets 2
打开系统设置页跳转到 CW2 设置页
切换深/浅色主题切换 CW2 主题

显示与提醒

行动说明
全屏播放文字全屏或顶部横幅播放文字；超出屏宽自动从右往左滚动；高度按字号自适应；时长填 0 = 一直循环；上课/活动期间拒绝外部插件推送的横幅
自动化提醒弹插件通知；可勾选「隐藏小组件时临时恢复显示」
倒计时提醒从设定秒数起每秒显示「还剩 N 秒」，结束后才执行下一步；同样支持隐藏时恢复显示
发系统通知发送系统级通知（需系统通知扩展）
课程展示模式联动「全量展示课程」插件：进入白板模式 / 息屏模式 / 退出特殊模式

流程与配置

行动说明
等待暂停指定 分 + 秒 后继续
广播信号向其它插件广播信号（配合「收到信号」触发器）
设标志设置一个可被条件判断的标志位
设置配置项修改 CW2 配置
触发随机点名 / 设置随机点名 / 关闭点名窗口联动随机点名插件（需安装）

其他

行动之外，每条自动化还支持「条件」判定（如当前科目、时间区间、前台窗口、标志位等 17 种），只有条件全部满足时行动才会执行；也支持「跑完自动停用」「恢复」等开关。
