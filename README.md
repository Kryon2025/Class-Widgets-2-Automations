# Kryon 自动化

为 Class Widgets 2 提供自动化能力，注册为官方 `AutomationTask`，随主程序每秒调度，无需自建后台线程。

## 模型

每条自动化 = **触发器列表（任一触发）+ 规则集（条件，满足才执行）+ 行动列表（顺序执行）**，
并支持「恢复」机制：逆事件（如下课）或规则集不再满足时，自动还原被修改的配置。

## 触发器（10 种）

| 类型 | 说明 |
|---|---|
| 定时 | 指定 HH:MM + 星期（留空=每天） |
| 间隔触发 | 每 N 秒一次 |
| 上课时 / 下课时 / 课间休息时 / 放学时 | 课表状态事件 |
| 时间状态变化时 | 任何状态切换 |
| 上课前 N 秒 | 下一节开始前触发 |
| 应用启动时 | 主程序启动后 |
| 收到信号 | 配合「广播信号」行动，规则间联动 |

## 规则（12 种，可组合 + 逻辑模式 + 取反）

总是为真 / 总是为假；今天是…（周几/周末/工作日）；时间晚于…；
当前科目是 / 下节课科目是 / 上节课科目是；当前时间状态是；前台窗口（进程名/标题 + 最大化/全屏）；
读标志；当前教师是 / 下节课教师是。

规则集支持「全部满足 / 任一满足」逻辑模式，以及整体取反与单条规则取反。

## 行动（8 种，可排序）

| 类型 | 说明 |
|---|---|
| 运行命令/程序 | 命令、程序或网址 |
| 显示提醒 | 灵动通知（标题/正文/时长/级别） |
| 等待 | 暂停 N 秒再执行下一条 |
| 广播信号 | 触发「收到信号」触发器 |
| 设标志 | 设定标志供「读标志」规则判断 |
| 设置配置项 | 主题/锚点/层级/偏移/隐藏小组件/迷你模式/组件方案/不透明度/缩放/光影/倒计时精度/悬停淡出/点击行为/通知等 20 项 |
| 锁定配置项 | 锁定/解锁指定配置键 |
| 重启主程序 | 重启 Class Widgets 2 |

## 典型用法

1. **上课隐藏、下课自动还原**：触发器加「上课时」，行动加「设置配置项 → 隐藏小组件 → 开」，并打开「恢复」开关（下课时自动还原，无需再建一条）。
2. **预备铃**：触发器「定时 07:50」，行动「运行命令」填音乐路径（如 `start "" "D:\预备铃.mp3"`）。
3. **仅数学课显示提醒**：触发器「上课时」+ 规则集「当前科目是 = 数学」+ 行动「显示提醒」。
4. **规则联动**：自动化 A 行动「广播信号 bell」，自动化 B 触发器「收到信号 bell」→ 执行。
5. **放学自动关机**：触发器「放学时」→ 行动「运行命令」`shutdown /s /t 60`。

## 安装与存储

1. 安装 `com.kryon.automations.cwplugin`，重启主程序。
2. 打开「设置 → 自动化」配置规则；「测试执行」可立即试跑一条规则。
3. 规则与标志保存在主程序 `configs/plugins/com.kryon.automations.json`，卸载插件不丢数据。

## 暂未支持的能力

- 天气类规则/行动（CW2 无内置天气服务）。
- 调用 URI 触发器（CW2 无 URI 调用机制）。
- 语音播报（CW2 无 TTS 朗读，由通知提示音承担）。
