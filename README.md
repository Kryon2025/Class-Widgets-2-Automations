## 功能特性

### 2.1.0 相比上游新增

- **上课/下课触发可限定科目**（2.1.0 新增）：「上课时」「下课时」两个触发器的字段里多了科目下拉，选中后只有该科目的课才触发；留「任意课」则每节都触发。
- **「课程展示模式」行动**（2.1.0 新增）：可切换白板模式 / 息屏模式 / 退出特殊模式，联动「全量展示课程」插件（com.yersmagit.lessonsdisplayer）；插件不在场时只记一条警告，不影响其他行动。

### 原有功能（继承自 Kryon 自动化 2.0.7，未删改）
- **触发器 + 规则集 + 行动**三段式自动化：触发器触发 → 规则集过滤 → 依次执行行动。
- **自动恢复**：开启「恢复」后，逆事件（如下课）或规则集不再满足时，自动还原被修改的配置。
- **类型专属编辑**：每种触发器/规则/行动选中后只显示自己需要的字段——下拉、开关、数字、时间、文本，无需手填参数。
- **窗口规则调试工具**：内置置顶小窗，一键查看任意窗口的句柄/类名/标题/状态/进程名，方便配置「前台窗口…」规则。
- **下拉选项实时接入主程序**：科目、教师、主题、组件方案等选项直接读取当前课表与主程序配置。
- **卡片式列表 + 上浮编辑页**：每条自动化是一张卡片，名称、说明、触发器与行动一目了然；点卡片打开编辑页。
- **打开已安装应用**：行动可下拉选择本机已安装的应用（含 UWP/商店应用），也可手填路径、网址或 `shell:AppsFolder\…`，支持启动参数与工作目录。
- **扩展功能开关**：「随机点名联动」与「系统通知」两个开关收在设置页顶部可展开的「扩展功能」折叠列表里，默认收起；关掉后对应模块不再出现在三个下拉里。随机点名那个首次运行会按本机是否装了点名插件自动定值，之后以你的手动选择为准。
- **隐藏时也能弹提醒**：「显示提醒」行动可单独开启「在隐藏状态下恢复显示」——小组件层当前是隐藏的，就先临时把那一层放出来，让灵动通知有落脚点；通知播完再自动收回原状（与点名插件同一套做法）。
- **规则导出 / 导入**：把全部自动化导出成一个 JSON 文件带到别的机器；导入时先预览条数与规则名，再选「合并到现有规则」（重复的自动跳过）或「替换全部现有规则」。还能勾上「导入后先设为停用」，避免别处拿来的关机 / 重启规则立刻生效。

## 模型

每条自动化 = **触发器列表（任一触发）+ 规则集（条件，满足才执行）+ 行动列表（顺序执行）**，
并支持「恢复」机制：逆事件（如下课）或规则集不再满足时，自动还原被修改的配置。

**没开「恢复」的自动化只执行一次**：行动跑完会自动把它的启用开关关掉（卡片标题会多出「（已停用）」），需要反复触发就打开「恢复」。

## 触发器（16 种）

| 类型 | 说明 |
|---|---|
| 定时 | 指定 HH:MM + 星期（留空=每天） |
| 间隔触发 | 每 N 秒一次 |
| 上课时 / 下课时 / 课间休息时 / 放学时 | 课表状态事件；**上课/下课可限定科目**（2.1.0 新增，见下）。（放学时见下方说明） |
| 时间状态变化时 | 任何状态切换 |
| 上课前 N 秒 | 下一节开始前触发 |
| 应用启动时 | 主程序启动后 |
| 收到信号 | 配合「广播信号」行动，规则间联动 |
| 闹钟 | 指定 HH:MM，到点弹系统通知并响铃（见下方「定时与闹钟」） |
| 开机后 | 系统开机后主程序首次启动时 |
| 系统设置变化时 | 主程序里任意配置项发生变化时 |
| 收到系统通知时 | 系统弹出通知时 |
| 随机点名开始 | 点名插件开始滚动时（需点名插件 + 扩展开关） |
| 随机点名出结果后 | 点名插件出结果时（需点名插件 + 扩展开关） |

| 时间晚于… | 时间 | 当前时刻晚于该时间则满足 |
| 当前科目是 / 下节课科目是 / 上节课科目是 | 下拉 | 直接选取课表中的科目 |
| 当前时间状态是 | 下拉 | 上课 / 课间休息 / 放学后 / 活动 / 预备 |
| 前台窗口… | 文本 + 下拉 | 进程名或标题 + 包含/等于 + 任意/最大化/全屏（配合窗口调试工具） |
| 读标志… | 文本 | 标志名 + 期望值（配合「设标志」行动） |

## 播放文字（全屏 / 顶部横幅）

- 行动「全屏播放文字」可以往屏幕上抹一段大字：`全屏` 是纯黑铺满整屏，`顶部横幅` 只在屏幕上方拉一条黑条，
  高度随字号自适应（字越大条越高），离屏幕顶端留一点空，下面的桌面和窗口照常能看能用（适合当通知条）。
- 文字宽度超过屏幕会从右往左滚动；没超屏就居中静止，静止时长填「停留秒数」（0 = 一直显示到手动词退出）。
- 播放时**右键**（触摸屏**长按 0.7 秒**）弹出菜单：**编辑文本**（带着当前文字、时长、速度、字号、显示方式回到输入界面）/ **退出**。
  按 `Esc` 也可以直接关掉。
- 设置页右上角还有「播放文字」按钮，可以直接打开同一个输入界面手动播一段，不用建自动化。

## 界面

- 「设置 → 自动化」是**卡片式列表**：每张卡片显示名称、描述、触发器与行动的摘要；已停用的卡片标题带「（已停用）」。
- 点任意卡片会打开**编辑页**（圆角卡片式），在里面改基础设置、触发器、规则集与行动。
- 编辑页是**草稿式**：改动先落在草稿上，点「保存」才写回配置并立即生效，点「取消」丢弃全部改动。
- 编辑页底部可「测试执行」（先保存，再忽略触发器与规则集立即执行一次）或「删除此自动化」（有二次确认）。
- 时间类字段用主程序同款的时间选择器，不必手填 `HH:MM`。
- 列表页顶部有一条**可关闭的「恢复」提示**：没开「恢复」的自动化只执行一次，跑完会自动停用；
  点提示条右上角的 ✕ 关掉后，之后打开设置页不再出现（状态记在本插件配置里）。
- 页头的「导入」「导出」管规则的搬运：导出的文件带插件版本与导出时间，导入前会先弹出条数与规则名供确认。

## 定时与闹钟

- 「定时」触发器的星期是**七个复选框**：全选 = 每天（存成空值），全不选 = 不触发，
  其余情况存成 `1,3,5` 这种列表。
- 「定时」与「闹钟」都可以勾选**自动跳过非上课日**：当天课表里没有「课程」条目就不触发。
  主程序的课表本身已处理调休，所以法定假日、调休上课日都会自动算对。
- 「闹钟」是独立触发器类型：到点会弹一条**系统级通知**（标题 = 自动化名称）并**响铃**，
  不需要另外配「显示提醒」。铃音可选系统提示音 / 警告音 / 询问音 / 系统闹钟铃声，
  也可以选一个自定义 `.wav`。

## 「放学」是怎么判定的

**以主程序的状态为准**（与主程序自己发的通知、小组件显示保持一致）：

- 主程序报「空闲」（`free`）→ 视为放学后。
- 主程序报上课 / 课间 / 活动 / 预备 → 原样沿用，不做任何改判。
- 「放学时」触发器同样在这一刻触发（上一刻还不是空闲，此刻变成空闲）。

只有拿不到主程序状态时（接口异常等），才退回按课表推算：
当天没有课程/课间 → 一整天算放学；相邻「课程/课间」之间的空档**超过 1 小时** →
该空档算放学（刚好 60 分钟不算）；活动、预备不参与推算；第一节课前不算放学。

## 窗口规则调试工具

配置「前台窗口…」规则时，需要知道某个窗口的进程名/标题：

1. 在「设置 → 自动化」页右上角（标题右侧）点击「窗口调试」。
2. 弹出的置顶小窗会实时显示**当前前台窗口**的窗口句柄、窗口类名、窗口标题、窗口状态、窗口进程名。
3. 点击你要查询的窗口，小窗即切换为该窗口的信息；窗口保持置顶不被遮挡。
4. 把查到的进程名或标题填进「前台窗口…」规则即可。

## 典型用法

1. **上课隐藏、下课自动还原**：触发器加「上课时」，行动加「设置配置项 → 隐藏小组件 → 开」，并打开「恢复」开关（下课时自动还原，无需再建一条）。
2. **预备铃**：触发器「定时 07:50」，行动「运行命令」填音乐路径（如 `start "" "D:\预备铃.mp3"`）。
3. **仅数学课显示提醒**：触发器「上课时」+ 规则集「当前科目是 = 数学」+ 行动「显示提醒」。
4. **规则联动**：自动化 A 行动「广播信号 bell」，自动化 B 触发器「收到信号 bell」→ 执行。
5. **放学自动关机**：触发器「放学时」→ 行动「运行命令」`shutdown /s /t 60`。
6. **玩游戏时自动隐藏小组件**：触发器「应用启动时」+ 规则集「前台窗口… 进程名包含 = 游戏进程（用窗口调试工具查询）」+ 行动「设置配置项 → 隐藏小组件 → 开」。
7. **放学自动打开浏览器**：触发器「放学时」→ 行动「打开应用」→ 下拉选 Chrome，启动参数填 `--new-window`。
8. **放学后放歌**：触发器「放学时」→ 行动「打开应用」→ 选你的播放器（UWP 应用也在下拉列表里）。

9. **仅数学课进白板模式**：触发器「上课时」（科目选「数学」，不用再配规则集）→ 行动「课程展示模式 → 白板模式」，并打开「恢复」开关——下课时自动执行逆行动（退出特殊模式）。
10. **自习课自动息屏**：触发器「上课时」（科目选「自习」）→ 行动「课程展示模式 → 息屏模式」。
11. **考试时提醒安静**：触发器「上课时」+ 规则集「当前科目是 = 考试」→ 行动「全屏播放文字」填「考试中，请保持安静」，显示方式选「顶部横幅」。

## 安装与存储

1. 安装 `org.cslblog.betterautomations.cwplugin`，重启主程序。
2. 打开「设置 → 自动化」：点「新建自动化」建规则，卡片列表会列出所有自动化；编辑页里「测试执行」可立即试跑，保存后立即生效。
3. 规则与标志由主程序的 **ConfigAPI** 托管（`register_plugin_model`），改动即时保存；
   只有在拿不到官方配置接口（较老宿主）时，才回退到 `configs/plugins/org.cslblog.betterautomations.json` 保底。
   **从旧插件「Kryon自动化」迁移**：首次启动时若本插件还没有规则文件，而 `configs/plugins/com.kryon.automations.json` 存在，
   会自动把它复制为本插件的规则文件，原有规则不丢。迁移后请停用或卸载旧插件，避免两套引擎重复触发。

## 已知问题

### 小组件隐藏后恢复显示时，组件框被裁剪

**现象**：小组件层处于隐藏状态时，勾了「在隐藏状态下恢复显示」的「显示提醒」会先把那一层临时放出来；
之后再恢复显示，组件框尺寸不对，内容被裁掉一截。用鼠标点一下组件，它重新排版后恢复正常。

**原因在主程序，不在本插件。**
主程序 `BaseWidget.qml` 里组件宽度是实时算出来的：
`implicitWidth: Math.max(headerRow.implicitWidth, visibleContentWidth()) + 48`，
同时又给它挂了 `Behavior on implicitWidth`，缓动用的是 `liquidBack`（带回弹，会冲过目标值再弹回来）。
层从隐藏恢复时，宽度从旧值弹向新值并过冲，这期间算出来的是中间态，内容就按错误的宽度排版了。

**为什么插件侧改不动**：宽度由基类计算并掌控，插件能改的 `width` / `visible` / `opacity` 全在这套计算的下游。
已实测「`width` 归零」「几何完全不变只改透明度」「强制 `update()` 重绘」三种做法，均无效。

**怎么绕过去**：等主程序修复。方向是层恢复时禁用这个 `Behavior`，或把 `liquidBack` 换成不过冲的缓动（如 `OutCubic`）。
